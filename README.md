# Classify

برنامهٔ کلاسی و تکالیف برای مدرسه: هر کلاس مدیر خودش را دارد؛ دانش‌آموز فقط نام و کلاسش را انتخاب می‌کند.

- `app/` — اپ اندروید (Kotlin + Jetpack Compose)
- `server/` — سرور (Flask + SQLite)، راهنما در `server/README.md`
- `.github/workflows/build.yml` — ساخت خودکار APK با GitHub Actions (فایل `app-debug` در بخش Artifacts)

## شروع سریع
1. سرور را اجرا کنید و رمز مدیر کل را بردارید.
2. اپ را نصب کنید، با نقش «مدیر کل» وارد شوید و کلاس‌ها را با رمز مدیر هر کلاس بسازید.
3. مدیر هر کلاس وارد می‌شود، لیست دانش‌آموزان، درس‌ها (می‌توانید عکس بگذارید)، برنامه و تکالیف را می‌سازد.
4. دانش‌آموزان آدرس سرور، کلاس و نامشان را وارد می‌کنند.
