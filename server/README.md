# سرور Classify

## راه‌اندازی برای تست (Termux)
```
pkg install -y python
pip install flask
python app.py
```
بار اول، `config.json` ساخته می‌شود و **رمز مدیر کل** چاپ می‌شود. آن را فقط خودتان بدانید.
(برای تعیین دستی: متغیر محیطی `CL_SUPER_PASSWORD`.) فایل‌های `config.json` و `classify.db` روی GitHub نمی‌روند.

برای استفادهٔ واقعی، سرور را روی VPS با آدرس ثابت و HTTPS بگذارید: `deploy/README.md`.

## نقش‌ها
| نقش | ورود | کار |
|---|---|---|
| مدیر کل | رمز مدیر کل | ساخت کلاس، تعیین رمز مدیر هر کلاس، تغییر نام/رمز، حذف کلاس |
| مدیر کلاس | انتخاب کلاس + رمز آن کلاس | لیست دانش‌آموزان، درس‌ها (با عکس)، برنامه، تکالیف، اعلان‌ها، مسدود کردن |
| دانش‌آموز | انتخاب کلاس + نام + نام خانوادگی | دیدن برنامه، تکالیف و اعلان‌های کلاس خودش |

## امنیت ورود دانش‌آموز
- فقط نام‌هایی که مدیر کلاس در لیست وارد کرده می‌توانند وارد شوند؛ اختلاف «ی/ي»، «ک/ك»، نیم‌فاصله و «آ/ا» نادیده گرفته می‌شود.
- هر نام به **اولین دستگاهی** که واردش شود قفل می‌شود.
- ورود از دستگاه دیگر **کد تأیید ۶ رقمی** می‌خواهد که دستگاه اول (تنظیمات ← «کد تأیید برای دستگاه جدید») نشان می‌دهد؛ ۲ دقیقه اعتبار دارد و ۵ بار حدس مجاز است. بعد از تأیید، دستگاه قدیمی خارج می‌شود.
- اگر دستگاه گم شد یا کسی زودتر اسم را اشغال کرد، مدیر کلاس «آزاد کردن دستگاه» را می‌زند.
- مدیر کلاس می‌تواند دانش‌آموز را برای هر مدتی (از ۱ دقیقه) مسدود یا از لیست حذف کند.

## API
| مسیر | نقش | کار |
|---|---|---|
| `GET /api/classes` | — | لیست کلاس‌ها |
| `POST /api/login/super` · `/manager` · `/student` | — | ورود |
| `POST /api/student/verify` | — | ورود با کد تأیید دستگاه جدید |
| `POST /api/student/pair-code` | دانش‌آموز | ساخت کد تأیید |
| `GET/PUT /api/class/data` | دانش‌آموز+مدیر / مدیر | درس‌ها، برنامه، تکالیف، اعلان‌ها |
| `GET/PUT /api/class/courses/<id>/photo` | هر دو / مدیر | عکس درس (JPEG) |
| `GET/POST /api/class/students` · `DELETE …/<id>` · `POST …/<id>/release` · `…/<id>/block` | مدیر | مدیریت دانش‌آموزان |
| `GET /api/app/<student\|manager>/latest` · `…/download` | — | آخرین نسخهٔ اپ و دانلود APK |
| `POST /api/app/<student\|manager>/publish` | توکن انتشار | انتشار نسخهٔ جدید (APK + meta) |
| `GET/POST /api/admin/classes` · `PUT/DELETE …/<id>` | مدیر کل | مدیریت کلاس‌ها |

«انجام شد» روی سرور ذخیره نمی‌شود و فقط روی گوشی هر دانش‌آموز می‌ماند.
